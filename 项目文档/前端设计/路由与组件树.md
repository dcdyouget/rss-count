# 路由与组件树

## 路由配置

```typescript
const router = createBrowserRouter([
  {
    path: '/',
    element: <AppLayout />,
    children: [
      { index: true, element: <Dashboard /> },
      { path: 'tasks', element: <TaskManagement /> },
      { path: 'reports', element: <ReportManagement /> },
      { path: 'reports/:id', element: <ReportDetail /> },
      { path: 'news', element: <NewsManagement /> },
      { path: 'news/:id', element: <NewsDetail /> },
      { path: 'drafts', element: <DraftManagement /> },
      { path: 'drafts/new', element: <DraftEditor /> },
      { path: 'drafts/:id', element: <DraftEditor /> },
      { path: 'rss-sources', element: <RssSourceManagement /> },
      { path: 'settings', element: <Settings /> },
    ],
  },
]);
```

## AppLayout 布局

```
┌──────────────────────────────────────────────┐
│  Logo    RSS Count                           │  ← Header
├──────────┬───────────────────────────────────┤
│          │                                   │
│  仪表盘   │                                   │
│  任务管理 │         <Outlet />                │  ← Content
│  报告管理 │       (子路由渲染区域)              │
│  新闻管理 │                                   │
│  稿件管理 │                                   │
│  RSS源   │                                   │
│  设置    │                                   │
│          │                                   │
└──────────┴───────────────────────────────────┘
     ↑ Sider                        ↑ Content
  (200px fixed)                  (flex: 1)
```

使用 Ant Design `Layout` + `Menu`（inline 模式，高亮当前路由）。

## 共享组件清单

| 组件 | 使用页面 | 说明 |
|---|---|---|
| `NewsCard` | ReportDetail, NewsManagement | 新闻圆角卡片，缩略图+标题+概览+来源 |
| `NewsCardGrid` | ReportDetail | 响应式网格容器 |
| `NewsContent` | ReportDetail, NewsDetail | 新闻完整内容（正文+侧边栏） |
| `StructuredContentRenderer` | NewsContent 内部 | JSON 结构化正文 → React 组件 |
| `ThreeStepProgress` | TaskDetailDrawer | 三节点进度指示器 |
| `StatusTag` | TaskManagement, Dashboard, NewsManagement | RUNNING/COMPLETED/FAILED 彩色标签 |
| `SourceSelector` | CreateTaskDrawer | RSS 源/分组多选组件 |
| `TimeRangePicker` | CreateTaskDrawer | 时间预设 + 自定义范围 |
