# 页面设计

## 1. 仪表盘 (Dashboard)

### 布局
上下两部分：上排 3 个 StatCard + 创建任务按钮，下排 60% 最近任务 + 40% 最近报告。

### StatCard 组件
```typescript
interface StatCardProps {
  title: string;
  today: number;
  yesterday: number;
  change: number;
  changePercent: number | null;
}
```
- 展示：大数字 + `↑/↓ N (X%)` 或 `新增 N`（昨天为 0）
- 颜色：增长绿色 ↑，下降红色 ↓
- 点击：跳转到对应管理页（任务→/tasks, 报告→/reports, 新闻→/news）

### 最近任务列表
- 来源：`GET /dashboard/recent-tasks`
- 每条：标题 + 状态标签 + 时间范围 + 开始/结束时间
- COMPLETED：`[查看报告 →]` 跳转 `/reports/:reportId`
- RUNNING/FAILED：`[查看详情 →]` → 跳转 `/tasks` 并打开该任务详情 Drawer
- 底部：`查看全部任务 →` 跳转 `/tasks`

### 最近报告列表
- 来源：`GET /dashboard/recent-reports`
- 每条：报告名 + 新闻数 + 生成时间
- 底部：`查看全部报告 →` 跳转 `/reports`

### 状态
| 场景 | 行为 |
|---|---|
| 数据全部为 0 | 正常显示 0，"昨日无数据" |
| 接口失败 | 卡片显示 `--`，Toast 提示 |
| 首次使用 | 任务/报告列表显示 Empty + 引导按钮 |

## 2. 任务管理 (TaskManagement)

### 任务列表
- Table 分页，按 createdAt DESC
- 筛选栏：状态下拉 + 创建时间范围 DatePicker
- 操作列：
  - COMPLETED：`查看报告`（跳转）+ `查看详情`（Drawer）
  - 其他状态：`查看详情`（Drawer）

### 创建任务 Drawer
右侧滑出 400px。

**时间范围选择**：
- 预设：1小时前 / 6小时前 / 截止上次任务结束
- "截止上次" → 调 `GET /tasks/last-end-time`
  - 有值：显示具体时间（如"截止 05-20 08:00"）
  - 无值：选项 disabled + Tooltip "暂无历史任务"
- 自定义 → 展开 DatePicker.RangePicker

**RSS 源选择 SourceSelector**：
- 三种模式 Radio：全部 / 分组 / 指定源
- 分组模式 → 多选下拉（查 rssGroups）
- 指定源模式 → 搜索多选下拉（查 rssSources）
- 默认选中"全部"

**提交**：
- 校验通过 → POST /tasks → 关闭 Drawer → 刷新列表
- 失败 → message.error，保留表单

### 任务详情 Drawer
右侧滑出 500px。

**ThreeStepProgress**：
- 使用 Ant Design Steps 组件
- 状态来源：SSE progress 事件
- 动画：当前阶段节点脉动（CSS animation pulse）

**日志区（RUNNING）**：
- Ant Design Timeline 组件
- 每条 SSE progress → 追加一行日志
- 自动滚动到底部（useEffect + scrollIntoView）
- 保留最近 200 条

**完成区（COMPLETED）**：
- 源列表：去重 sourceRssName + fetchedCount
- 新闻列表：分页（每页 10 条，在 Drawer 内）
- `[查看报告 →]` 按钮

**SSE 断开**：
- 显示 "连接断开，正在重连..." 
- 30s 内重连成功 → 继续
- 超时 → 提示用户刷新

## 3. 报告管理 (ReportManagement)

### 报告列表
- Table 分页，按 createdAt DESC
- 操作：`查看` → `/reports/:id`

### 报告详情 (ReportDetail)

**视图模式**：
- `grid`：左侧目录 + 右侧新闻卡片网格
- `detail`：单条新闻内容展开

**TOC 左侧目录**：
- Ant Design Anchor 组件（或自定义滚动列表）
- 从 News 列表生成锚点
- 当前可视新闻高亮（IntersectionObserver）
- 点击 → `scrollIntoView` + 切换到 grid 模式

**新闻卡片网格**：
- 响应式布局：大屏 3 列，中屏 2 列
- 每张卡片：头图（160×120）+ 标题（2行截断）+ 概览（3行截断）+ 来源
- 点击 → 切换到 detail 模式

**视图切换**：
- 使用 framer-motion `AnimatePresence` 实现 fade + slide 过渡
- 或简单 CSS transition opacity 0.3s

### 新闻内容视图 (NewsContent)
- 从卡片展开后占满右侧内容区
- 顶部：`← 返回报告` 按钮 + 标题
- 小字：来源 + 发布时间
- 主体：`StructuredContentRenderer` 渲染 JSON
- 右侧边栏：作者、标签(Tag)、原文链接、标记已读、加入/移出素材堆

**StructuredContentRenderer**：
```typescript
// 遍历 structuredContent JSON 数组
{content.map((node, i) => {
  switch (node.type) {
    case 'heading': return <Typography.Title level={node.level}>...
    case 'paragraph': return <Typography.Paragraph>...
    case 'image': return <Image src={node.src} alt={node.alt} />...
    case 'blockquote': return <blockquote>...
    case 'list': return node.ordered ? <ol> : <ul>...
    case 'code': return <pre><code>...
  }
})}
```

## 4. 新闻管理 (NewsManagement)

### 新闻列表
- Table (rowSelection) + 分页
- 列顺序：头图(Image 40×40) → 标题 → 来源 → 所属报告(Link) → 发布时间 → 操作(详情)
- 筛选：标题关键字搜索 + 报告名筛选 + 已读状态
- 批量操作：选中 → "加入素材堆"

### 新闻详情 (NewsDetail)
- 复用 `NewsContent` 组件
- 上下文不同：返回按钮跳 `/news` 而非报告详情
- 侧边栏功能相同

## 5. 稿件管理 (DraftManagement)

### 稿件列表
- Table 分页：名称 + 风格 + 平台 + 新闻数 + 更新时间 + 操作
- `新建稿件` → `/drafts/new`

### 稿件编辑器 (DraftEditor)
左右分栏。

**左侧面板（350px）**：
- 素材堆：Card 内 List，显示标题 + 加入时间（只读）
- 提示词：TextArea 4 行
- 温度：Slider (0.0~2.0, step=0.1) + 当前值显示
- 风格：Select（正式/轻松/客观/犀利/幽默）
- 平台：Select（知乎/今日头条/小红书/小黑盒/通用）
- `AI 生成稿件` 按钮

**右侧面板（flex:1）**：
- Tabs：`富文本` | `纯文本`
- 富文本 Tab → TipTap 编辑器（可编辑）
  - 工具栏：Bold, Italic, H1-H3, Blockquote, BulletList, OrderedList, Link
- 纯文本 Tab → TextArea（可编辑，等宽字体）
- 右下角 `复制内容` 按钮：`navigator.clipboard.writeText()`

**自动保存**：
- 防抖 2 秒 → PUT /drafts/{id}
- 保存中：PageHeader 显示 "保存中..."
- 已保存：显示 "已保存 15:30"
- 离开确认：`isDirty === true` → Popconfirm 提示

**AI 生成**：
- 校验：素材堆非空 → 否则 button disabled + Tooltip "请先在新闻管理中添加素材"
- 生成中：按钮 loading + 左侧表单 disabled
- 成功：内容填入编辑器 + `latestVersion` + 1
- 失败：message.error + 保留旧内容

## 6. RSS 源管理 (RssSourceManagement)

### 分组标签栏
- 遍历 rssGroups → 渲染 Tab
- 选中：高亮 + 过滤表格
- `＋` 按钮：行内 Input → 输入名称 → 回车创建
- 右键分组名：Dropdown（重命名 / 删除）

### 源表格
- 图标：`<img src={iconPath}>` 或 Avatar fallback
- 最近拉取：格式化时间，无数据显示 "从未"
- 拉取总数：数字
- 删除：Popconfirm "确定删除？历史新闻不受影响" → PUT isActive=false

### 添加源 Modal
- RSS 地址必填 + 名称可选 + 分组多选
- 提交 → POST /rss-sources → 后端验证 RSS 可达性 + 下载 favicon
- 可能较慢（3-10 秒），按钮需 loading

### OPML 导入
- Ant Design Upload.Dragger
- 接受 .opml, .xml
- 上传完成 → 显示结果 Modal：创建 N 个，跳过 M 个

### OPML 导出
- 直接下载：`<a href="/api/v1/rss-sources/export-opml" download>`

## 7. 设置 (Settings)

### 表单
- 定时任务间隔：InputNumber (0-168)，0=禁用
- AI 配置：URL + Key(Password) + Model
- 默认分组：Select（查 rssGroups）
- `保存设置` → PUT /settings

### API Key 特殊处理
- GET 返回脱敏 key → 显示在 Input.Password 中
- 用户修改 key → PUT 传新值
- 用户未修改 → PUT 传 `******` → 后端保留旧值
- Input 右侧 👁 图标切换显示/隐藏
