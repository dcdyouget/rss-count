# 前端开发任务清单

## 使用说明

每个任务自包含。Agent 拿到任务后：
1. 读取本任务的"需阅读文档"
2. 按"验收标准"完成开发（TDD：先写测试）
3. 遵守 `设计规范.md` 全部约束
4. 并行标识 `∥` = 可与其他同阶段任务同时执行

---

## 阶段 0：基础设施 ⚠️ 1 人，锁，必须先完成

> 本阶段为所有页面提供统一的主题、布局和类型基础。其他 agent 等本阶段完成后才能开始。

- **需阅读**：`技术选型.md`
- **内容**：`npm create vite@latest` → React + TypeScript，安装 antd / react-router / @tanstack/react-query / zustand / axios / dayjs / @tiptap/react / framer-motion
- **验收**：`npm run dev` 启动成功

### 0.2 类型定义 + 工具函数 ∥
- **需阅读**：`状态管理与数据流.md`、后端 `API设计.md`（对照 DTO 定义 TS 类型）

### 0.4 AppLayout + 路由骨架

## Agent 自检清单

每个 agent 提交任务前自查：

- [ ] 读了本任务标注的"需阅读文档"
- [ ] 颜色/字号/圆角/间距遵守 `设计规范.md`
- [ ] 无硬编码颜色（`#xxx`）、无大段 `style={{}}`
- [ ] 表格用 `<Table>`、表单用 `<Form>`、弹窗用 `<Drawer>`/`<Modal>`
- [ ] 空状态用 `<Empty>`、加载用 `skeleton`/`Spin`
- [ ] 使用了已有的共享组件，不自造轮子
- [ ] 对照了对应原型图
- [ ] 测试通过
