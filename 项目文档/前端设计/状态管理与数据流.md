# 状态管理与数据流

## 概述

- **服务端状态**：TanStack Query 管理，自动缓存、去重、后台刷新
- **客户端状态**：Zustand 管理，用于 UI 状态、编辑器草稿、选中项
- **SSE**：自定义 `useSSE` Hook，与 TanStack Query 集成

---

## TanStack Query 配置

```typescript
// App.tsx
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 30_000,        // 30s 内不重新请求
      retry: 1,                 // 失败重试 1 次
      refetchOnWindowFocus: false,
    },
  },
});
```

## API 调用模式

### GET 列表（分页）
```typescript
// api/tasks.ts
export function useTasks(params: TaskListParams) {
  return useQuery({
    queryKey: ['tasks', params],
    queryFn: () => client.get('/tasks', { params }).then(r => r.data),
  });
}
```

### GET 详情
```typescript
export function useTask(id: number) {
  return useQuery({
    queryKey: ['tasks', id],
    queryFn: () => client.get(`/tasks/${id}`).then(r => r.data),
    enabled: !!id,
  });
}
```

### POST/PUT/DELETE（Mutation）
```typescript
export function useCreateTask() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (data: CreateTaskDTO) => client.post('/tasks', data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['tasks'] });
      queryClient.invalidateQueries({ queryKey: ['dashboard'] });
    },
  });
}
```

## useSSE Hook

```typescript
// hooks/useSSE.ts
interface SSEProgress {
  pulling: { done: boolean; currentSource?: string; sourceProgress?: string; totalFetched?: number };
  formatting: { done: boolean; formatted?: number; total?: number; currentAction?: string };
}

interface UseSSEResult {
  progress: SSEProgress | null;
  logs: string[];
  isComplete: boolean;
  error: string | null;
  isConnected: boolean;
}

function useSSE(taskId: number | null): UseSSEResult {
  // 1. taskId 变化或首次挂载 → new EventSource(url)
  // 2. onmessage → parse JSON → 分三种:
  //    - progress: 更新 progress 状态 + push log
  //    - complete: isComplete = true + close EventSource
  //    - error: error = message + close EventSource
  // 3. onerror → 重连逻辑（30s 内最多 3 次）
  // 4. 组件卸载 → close EventSource
  // 5. 返回 { progress, logs, isComplete, error, isConnected }
}
```

### SSE 与 TanStack Query 集成

```typescript
// 在 TaskDetailDrawer 中
const { progress } = useSSE(taskId);
// SSE complete 时触发 refetch
const queryClient = useQueryClient();
useEffect(() => {
  if (isComplete) {
    queryClient.invalidateQueries({ queryKey: ['tasks', taskId] });
  }
}, [isComplete]);
```

## useAutoSave Hook

```typescript
// hooks/useAutoSave.ts — 稿件编辑器防抖自动保存
function useAutoSave(draftId: number, content: string, delay: number = 2000) {
  const [isSaving, setIsSaving] = useState(false);
  const [lastSaved, setLastSaved] = useState<Date | null>(null);

  // debounce: content 变化 → 等 delay → PUT /drafts/{id}
  // isSaving: PUT 进行中
  // lastSaved: PUT 成功后更新
  return { isSaving, lastSaved };
}
```

## 数据流总览

```
                   TanStack Query Cache
                        │
  ┌─────────────────────┼─────────────────────┐
  │                     │                     │
  ▼                     ▼                     ▼
useQuery            useMutation           useSSE
(GET 缓存)          (POST/PUT/DEL)        (实时推送)
  │                     │                     │
  ▼                     ▼                     ▼
Component           invalidate           setQueryData
(渲染)              (刷新列表)           (更新任务详情进度)
                        │
                        ▼
                  Zustand Store
                  (UI 状态/草稿)
```

## API 调用汇总

每个页面的 API 调用：

| 页面 | 加载时调用 | 用户操作调用 |
|---|---|---|
| Dashboard | stats, recent-tasks, recent-reports (并行) | 创建任务 → navigate |
| TaskManagement | tasks 列表, rssGroups, rssSources, suggestName, lastEndTime | createTask, taskDetail, SSE |
| ReportManagement | reports 列表 | - |
| ReportDetail | report + news 列表 | news detail (同步数据已在列表) |
| NewsManagement | news 列表 | batch-material-pile |
| NewsDetail | news detail | mark read, material pile |
| DraftManagement | drafts 列表 | delete |
| DraftEditor | draft detail, material-pile, rssGroups | create/update draft, generate, autoSave |
| RssSourceManagement | rssSources, rssGroups | add, delete, import, export, group CRUD |
| Settings | settings, rssGroups | save |
