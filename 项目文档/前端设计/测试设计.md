# 前端测试设计

## 测试策略

- **测试框架**：Vitest + React Testing Library
- **E2E 测试**：Playwright（关键用户流程）
- **TDD 原则**：先写测试，再写组件

---

## 一、组件单元测试

### T1. StatCard（仪表盘统计卡片）

| 用例 | 输入 | 预期 |
|---|---|---|
| T1-1 | today=5, yesterday=3, change=2, pct=66.7 | 显示 "5" + "↑2 (66.7%)" + 绿色 |
| T1-2 | today=5, yesterday=0, change=5, pct=null | 显示 "5" + "新增 5"（不带 %） |
| T1-3 | today=0, yesterday=0 | 显示 "0"，无比较文字 |

### T2. StatusTag（状态标签）

| 用例 | 输入 | 预期 |
|---|---|---|
| T2-1 | RUNNING | 蓝色标签，文字 "执行中" |
| T2-2 | COMPLETED | 绿色标签，文字 "已完成" |
| T2-3 | FAILED | 红色标签，文字 "失败" |

### T3. ThreeStepProgress（三节点进度）

| 用例 | 输入 | 预期 |
|---|---|---|
| T3-1 | pulling.done=false, format.done=false | 节点1 active，节点2/3 wait |
| T3-2 | pulling.done=true, format.done=false | 节点1 finish，节点2 active，节点3 wait |
| T3-3 | both done=true | 全部 finish（绿色） |
| T3-4 | complete 事件 | 全部 finish |

### T4. StructuredContentRenderer（结构化正文渲染）

| 用例 | 输入 | 预期 |
|---|---|---|
| T4-1 | [{type:"heading",level:2,text:"标题"}] | 渲染 h2 |
| T4-2 | [{type:"paragraph",text:"文本"}] | 渲染 p |
| T4-3 | [{type:"image",src:"/img.jpg",alt:"图"}] | 渲染 img |
| T4-4 | 混合多种类型 | 正确渲染顺序 |
| T4-5 | 空数组 | 渲染 "暂无正文内容" |

### T5. NewsCard（新闻卡片）

| 用例 | 输入 | 预期 |
|---|---|---|
| T5-1 | title, summary, sourceRssName, headerImageUrl | 正确显示各字段 |
| T5-2 | 无 headerImageUrl | 显示占位图 |
| T5-3 | 点击 | 触发 onClick 回调 |
| T5-4 | 长标题 (>50字) | 截断 + Tooltip |

### T6. SourceSelector（源选择器）

| 用例 | 输入 | 预期 |
|---|---|---|
| T6-1 | 选择 "全部" | sourceType=ALL |
| T6-2 | 选择 "分组" + 选 2 个 | sourceType=GROUP, groupIds=[1,2] |
| T6-3 | 选择 "指定源" + 选 3 个 | sourceType=SOURCE, sourceIds=[1,2,3] |

## 二、Hook 测试

### T7. useSSE

| 用例 | 输入 | 预期 |
|---|---|---|
| T7-1 | EventSource 发 progress 事件 | progress 状态更新 + logs 追加 |
| T7-2 | EventSource 发 complete 事件 | isComplete = true, EventSource 关闭 |
| T7-3 | EventSource 发 error 事件 | error 赋值, EventSource 关闭 |
| T7-4 | EventSource 连接失败 | 重连最多 3 次，最终 error |
| T7-5 | 组件卸载 | EventSource.close() 被调用 |

### T8. useAutoSave

| 用例 | 输入 | 预期 |
|---|---|---|
| T8-1 | content 变化 → 等 2s | 触发 PUT 请求 |
| T8-2 | 2s 内再次变化 | 重置计时器，只发 1 次请求 |
| T8-3 | PUT 进行中 | isSaving = true |
| T8-4 | PUT 成功 | lastSaved 更新 |

## 四、E2E 测试（Playwright）

关键用户流程：

| 流程 | 步骤 |
|---|---|
| E1: 完整任务流程 | 添加 RSS 源 → 创建任务 → 等待完成 → 查看报告 → 查看新闻 |
| E2: 素材堆 + 稿件 | 浏览新闻 → 加入素材堆 → 创建稿件 → AI 生成 → 复制内容 |
| E3: OPML 导入 | 导入 OPML 文件 → 验证源列表 → 导出 → 验证文件 |

---

## 五、测试运行

```bash
# 单元测试
npx vitest run

# 带覆盖率
npx vitest run --coverage

# 单个测试文件
npx vitest run src/components/__tests__/StatCard.test.tsx

# E2E
npx playwright test
```
