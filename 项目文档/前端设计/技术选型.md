# 前端技术选型

## 概述

本项目前端为 SPA（单页应用），与后端 REST API + SSE 通信。需支持富文本编辑、SSE 实时推送、复杂交互（卡片展开动画、Drawer 滑出等）。

## 技术栈

| 层面 | 选型 | 版本 | 说明 |
|---|---|---|---|
| 框架 | React | 18+ | 生态最完整，富文本编辑器支持最好 |
| 构建工具 | Vite | 5+ | 快速 HMR，TypeScript 原生支持 |
| 类型 | TypeScript | 5+ | 类型安全，与后端 DTO 对应 |
| UI 组件库 | Ant Design | 5.x | 开箱即用，Table/Form/Drawer/Modal 齐全 |
| 路由 | React Router | 6.x | 标准 SPA 路由 |
| 服务端状态 | TanStack Query (React Query) | 5.x | API 缓存、分页、SSE 集成 |
| 客户端状态 | Zustand | 4.x | 轻量，用于 UI 状态、编辑器草稿 |
| 富文本编辑器 | TipTap | 2.x | 基于 ProseMirror，React 集成好，可定制 |
| 动画 | framer-motion | 10+ | 卡片展开/视图切换过渡动画 |
| HTTP 客户端 | axios | 1.x | 拦截器、错误处理 |
| 日期处理 | dayjs | 1.x | Ant Design 内置依赖，轻量 |

## 关键库说明

### Ant Design 5.x
- Table：分页、排序、行选择（rowSelection）
- Drawer：右侧滑出面板（创建任务、任务详情）
- Modal：添加 RSS 源、OPML 导入结果
- Form：设置页表单、创建任务表单
- Steps：任务详情三节点进度
- Upload：OPML 文件上传
- Anchor：报告详情左侧目录
- 主题：可通过 ConfigProvider 自定义主题色

### TanStack Query
- `useQuery`：GET 请求缓存与自动刷新
- `useMutation`：POST/PUT/DELETE 请求
- `useInfiniteQuery`：无限滚动（可选，当前用分页）
- `queryClient.invalidateQueries`：数据变更后刷新列表
- SSE 集成：SSE 事件触发 `queryClient.setQueryData` 实时更新

### TipTap
- 扩展：StarterKit + Heading + Image + Link
- 输出：HTML 或 JSON（后端存原始字符串，前端处理格式）
- 工具栏：BubbleMenu 或 Fixed Menu
- 与 Ant Design 风格统一：自定义样式

### Zustand
```typescript
// draftStore — 稿件编辑器状态
interface DraftStore {
  isDirty: boolean;        // 内容是否已修改
  activeTab: 'richtext' | 'plaintext';
  setDirty: (dirty: boolean) => void;
  setActiveTab: (tab: string) => void;
}
```
