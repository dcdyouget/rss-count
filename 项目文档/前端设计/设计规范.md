# 前端设计规范

> **原型图**在 `项目文档/原型图/` 目录下，共 5 张。所有页面开发必须参考原型图的布局和交互风格。
>
> **风格定位**：现代 AI SaaS Dashboard，Notion 风格，极简科技感。大面积留白、浅色背景、蓝色主强调色、卡片化设计、柔和阴影、大圆角、细边框。报告页面偏向文章流/杂志阅读体验。

---

## 一、颜色体系

| Token | 色值 | 用途 |
|---|---|---|
| `colorPrimary` | `#2563EB` | 主色：按钮、链接、选中态、进度节点 |
| `colorPrimaryHover` | `#1D4ED8` | 主色悬停 |
| `colorPrimaryBg` | `#EFF6FF` | 主色浅底：选中行背景、标签底色 |
| `colorSuccess` | `#10B981` | 成功：COMPLETED 标签、完成节点 |
| `colorWarning` | `#F59E0B` | 警告：进行中状态 |
| `colorError` | `#EF4444` | 错误：FAILED 标签、删除按钮 |
| `colorBgLayout` | `#F8FAFC` | 页面底色（浅灰白） |
| `colorBgContainer` | `#FFFFFF` | 卡片/表格/白色容器 |
| `colorBgElevated` | `#FFFFFF` | 浮层/Drawer/Modal 背景 |
| `colorBorder` | `#E5E7EB` | 边框、分割线 |
| `colorText` | `#111827` | 主文字 |
| `colorTextSecondary` | `#6B7280` | 辅助文字（时间、来源、标签） |
| `colorTextTertiary` | `#9CA3AF` | 弱化文字（提示、占位符） |

**使用约束**：
- 永远不写硬编码颜色（`#xxx`），必须引用 Ant Design token
- 需要新颜色时先看 token 表有没有对应的，没有再新增

## 二、排版

| 层级 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| H1 | 28px | 600 | 1.3 | 报告标题、页面大标题 |
| H2 | 22px | 600 | 1.3 | 报告标题、卡片标题 |
| H3 | 18px | 600 | 1.4 | 区块标题、Drawer 标题 |
| H4 | 16px | 600 | 1.4 | 新闻卡片标题 |
| Body | 14px | 400 | 1.6 | 正文、表格内容、表单 |
| Small | 12px | 400 | 1.5 | 辅助信息：时间、来源、计数 |
| Caption | 11px | 400 | 1.5 | 极弱信息：标签备注 |

字体族：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`

**使用约束**：
- 正文统一 14px，不要出现 13px 或 15px
- 标题层级从 H1→H4 逐级往下用，不要跳级

## 三、圆角

| 场景 | 圆角值 | 说明 |
|---|---|---|
| 小元素（Tag、Badge、小按钮） | 6px | `borderRadiusSM` |
| 标准元素（Input、Select、Button、Table） | 8px | `borderRadius` |
| 卡片（Card、List item） | 12px | `borderRadiusLG` |
| 大容器（Modal、Drawer 内卡片） | 12px | 同 LG |

**使用约束**：
- 卡片一律 12px 圆角
- 表格、输入框 8px
- 禁止出现直角（`borderRadius: 0`）

## 四、阴影

| 场景 | 阴影值 | 说明 |
|---|---|---|
| 卡片默认 | `0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.02)` | 极轻微浮起 |
| 卡片 Hover | `0 4px 12px rgba(0,0,0,0.06)` | 悬停时加深 |
| Drawer/Modal | `0 20px 40px rgba(0,0,0,0.12)` | 强浮层 |
| 下拉菜单 | `0 4px 16px rgba(0,0,0,0.08)` | 中等浮层 |

**使用约束**：
- 阴影一律用 `box-shadow` 而非 `filter: drop-shadow`
- 不要自创阴影值，一律从上面 4 个选

## 五、间距

基于 4px 网格体系：

| Token | 值 | 用途 |
|---|---|---|
| `xs` | 4px | 图标与文字间距 |
| `sm` | 8px | 标签间距、表单项间距 |
| `md` | 16px | 卡片内 padding、列表项间距 |
| `lg` | 24px | 页面内容区 padding、卡片间距 |
| `xl` | 32px | 区块间距、大标题下间距 |
| `2xl` | 48px | 页面顶部留白 |

**使用约束**：
- 页面内容区统一 `padding: 24px`（Ant Design Content 默认）
- 卡片内部 `padding: 24px`
- 卡片之间 `gap: 16px`
- 表单项目间距用 Ant Form 默认（`8px`），不要自定义

## 六、布局规范

### 全局布局
```

│  Logo/标题                          240px    │  ← Header
├────────┬─────────────────────────────────────┤
│ 导航    │                                     │
│ 仪表盘  │                                     │
│ 任务    │         内容区                       │
│ 报告    │      (padding: 24px)                │
│ 新闻    │                                     │
│ 稿件    │                                     │
│ RSS    │                                     │
│ 设置    │                                     │
│        │                                     │

  220px                   flex:1
```

- 侧边栏：220px 固定宽度，浅色背景（`#F8FAFC`），当前项蓝色高亮 + 浅蓝背景
- 顶栏：48px 高度，白色背景，底部细分割线
- 内容区：白色背景，`padding: 24px`

### 页面内部布局模式

| 模式 | 用法 | 示例页面 |
|---|---|---|
| 全宽表格 | 筛选栏 + 表格 + 分页 | 任务列表、新闻列表、报告列表、稿件列表、RSS 源管理 |
| 统计卡片 + 双列列表 | Row/Col 上排卡片、下排 60/40 列表 | 仪表盘 |
| 左右分栏 | 左侧目录/配置 + 右侧内容 | 报告详情、稿件编辑器 |
| Drawer 浮层 | 右侧滑出，宽度 400-500px | 创建任务、任务详情 |
| 表单卡片 | Card 包裹 Form | 设置页 |

## 七、组件使用规范

### 必须遵守

- **表格**：一律用 `<Table>`，columns 定义列，`dataSource` 绑定数据。禁止手写 `<table>`。
- **表单**：一律用 `<Form>` + `<Form.Item>`。禁止手写 `<form>` 和裸 `<input>`。
- **弹窗**：创建/确认用 `<Modal>`，详情/侧面板用 `<Drawer>`（右侧滑出）。
- **卡片**：列表项用 `<Card>`，禁止用 `<div>` + 手写 CSS 模拟。
- **标签**：状态用 `<Tag>`，禁止手写彩色圆角 div。
- **分页**：用 Table 内置 `pagination` 或独立 `<Pagination>`。
- **图标**：用 `@ant-design/icons`，禁止裸 emoji 或手写 SVG。
- **空状态**：用 `<Empty>` 组件，带引导文案和操作按钮。

### 严格禁止

| 禁止 | 原因 |
|---|---|
| `style={{ color: '#xxx' }}` | 颜色硬编码，无法统一管理 |
| `style={{ margin: '...' }}` 大段内联样式 | 应使用组件 props 或 CSS Modules |
| 手写 `<div className="card">` + CSS | 应使用 Ant Design `<Card>` |
| 自定义 CSS 文件覆盖 Ant Design 样式 | 应通过 ConfigProvider token 统一配置 |
| 自己造轮子替代 Ant Design 组件 | 如手写 Select、手写 DatePicker |
| `font-size: 13px` 或 `15px` | 遵循排版体系 |

## 九、共享组件清单（必须先于页面开发）

| 组件 | 说明 | 被哪些页面使用 |
|---|---|---|
| `AppLayout` | 侧边栏 + 顶栏 + 内容区（`<Outlet>`） | 全部页面 |
| `StatusTag` | RUNNING(蓝)/COMPLETED(绿)/FAILED(红) | 仪表盘、任务、新闻 |
| `StatCard` | 统计数字 + 同比变化 | 仪表盘 |
| `NewsCard` | 新闻圆角卡片（头图+标题+概览+来源） | 报告详情 |
| `NewsCardGrid` | 新闻卡片网格容器 | 报告详情 |
| `NewsContent` | 新闻正文+侧边栏（结构化渲染+标签+操作） | 报告详情、新闻详情 |
| `StructuredContentRenderer` | JSON→React组件渲染 | NewsContent 内部 |
| `ThreeStepProgress` | 三节点进度 | 任务详情 Drawer |
| `SourceSelector` | RSS源/分组选择器 | 创建任务 Drawer |

**开发顺序**：AppLayout → 状态/统计类 → 卡片/内容类 → 特定功能类

## 十、Agent 开发检查清单

每个 agent 在提交页面代码前必须确认：

- [ ] 没有硬编码颜色值（`#xxx`）
- [ ] 没有 `style={{ }}` 内联样式（除非是动态计算的布局值）
- [ ] 使用了共享组件而非自造轮子
- [ ] 表格用 `<Table>`，表单用 `<Form>`，弹窗用 `<Drawer>` 或 `<Modal>`
- [ ] 圆角、阴影、间距使用 Ant Design token 默认值
- [ ] 字体大小在排版规范区间内
- [ ] 空状态用 `<Empty>`，加载中表用 `skeleton` 或 `Spin`
- [ ] 参照了对应原型图（`项目文档/原型图/`）的布局
- [ ] 组件文件名和目录结构遵循 `页面设计.md` 中的组件树
