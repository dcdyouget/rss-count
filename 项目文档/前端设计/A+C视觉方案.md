# RSS Count A+C 视觉方案

## 1. 设计定位

方向：现代资讯工作台 + 专业情报终端。

目标不是把现有后台简单“换皮”，而是重新明确产品主次：

- 新闻发现、筛选和阅读是一级体验。
- 任务、报告、RSS 源和设置是支撑能力。
- 高频操作尽量在一个视口内完成，减少页面跳转。
- 保持专业信息密度，同时避免传统管理后台的拥挤感。

## 2. 核心结构

### 全局框架

- 左侧主导航：76px 图标栏，固定展示主要模块。
- 次级侧栏：240px，根据当前模块显示来源、分组和筛选。
- 顶部工具栏：56px，包含页面标题、全局搜索和主要操作。
- 内容区：浅灰背景，内部使用白色面板分区。

### 新闻工作台

采用三栏结构：

1. 来源与筛选：分组、RSS 源、未读数量、快捷筛选。
2. 新闻列表：约 420px，紧凑图文列表，可连续浏览。
3. 阅读预览：占据剩余宽度，直接展示正文和操作。

点击新闻后只更新右侧阅读区，不跳转页面。列表保留当前位置和筛选状态。

## 3. 页面优先级

### 第一阶段

- AppLayout 全局框架
- 新闻工作台
- 新闻阅读区
- 仪表盘首页
- 全局主题与基础组件

### 第二阶段

- 报告详情
- 任务管理
- RSS 源管理
- 稿件管理
- 设置

## 4. 视觉规范

### 色彩

| 用途 | 色值 |
|---|---|
| 应用背景 | `#F4F6F8` |
| 主面板 | `#FFFFFF` |
| 深色导航 | `#17202A` |
| 主文字 | `#17202A` |
| 次要文字 | `#667085` |
| 弱文字 | `#98A2B3` |
| 边框 | `#E7EAF0` |
| 品牌蓝 | `#316BFF` |
| 浅蓝选中 | `#EEF4FF` |
| 成功绿 | `#12A66A` |
| 警示橙 | `#E98A15` |

品牌色只用于当前状态、主要按钮和关键链接，避免页面大面积发蓝。

### 圆角与阴影

- 页面面板：12px
- 按钮、输入框：8px
- 标签：6px
- 常规面板不使用明显阴影，依靠背景和边框建立层级。
- 浮层使用柔和阴影：`0 12px 32px rgba(20, 32, 51, 0.12)`。

### 字体

- 中文界面：系统字体、苹方、微软雅黑。
- 页面标题：20px / 600。
- 新闻标题：列表 15px / 600，正文 30px / 650。
- 正文：16px / 1.85，最大宽度 760px。
- 元信息：12px 或 13px。

## 5. 新闻工作台交互

### 来源侧栏

- 顶部展示“全部资讯”“未读”“素材堆”。
- 下方按分组展示 RSS 源，可折叠。
- 每项显示未读数量，选中项使用浅蓝背景。
- 底部提供“管理 RSS 源”入口。

### 新闻列表

- 顶部支持搜索和筛选：全部、未读、已收藏。
- 每条新闻展示来源、时间、标题、两行摘要和可选缩略图。
- 未读新闻标题加粗，并显示蓝色状态点。
- 当前阅读项使用浅蓝底和左侧 3px 品牌色。
- Hover 时显示加入素材、标记已读等快捷操作。

### 阅读区

- 标题区展示来源、发布时间、作者和原文链接。
- 正文居中，限制阅读宽度。
- 右上角固定操作：标记已读、加入素材堆、打开原文。
- 阅读区独立滚动，新闻列表位置不受影响。
- 后续可加入上一条/下一条快捷键。

## 6. 仪表盘调整

首页名称调整为“今日工作台”，结构从统计后台改成：

- 顶部问候与“立即拉取”主操作。
- 今日摘要：新增新闻、未读、素材、运行任务。
- 主要区域：最新资讯流。
- 右侧区域：任务状态、活跃来源、最近报告。

统计卡片尺寸缩小，新闻内容成为首页主体。

## 7. 响应式策略

- `>= 1440px`：完整三栏。
- `1100px - 1439px`：来源栏缩窄，阅读区保持优先。
- `768px - 1099px`：来源栏收起为抽屉，保留列表 + 阅读区。
- `< 768px`：列表与阅读区切换显示，底部使用移动导航。

## 8. 实施原则

- 保留 Ant Design，主要通过主题 token 和组合方式重塑界面。
- 不在第一阶段修改后端接口。
- 新闻页从 Table 改为语义化列表，管理类页面继续使用 Table。
- 将大量内联样式逐步迁移到页面级 CSS Module 或共享样式。
- 首次实施提供浅色主题，结构稳定后再增加深色主题。
