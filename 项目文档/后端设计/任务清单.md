# 后端开发任务清单

## 使用说明

每个任务自包含。Agent 拿到任务后：
1. 读取本任务的"需阅读文档"
2. 按"验收标准"完成开发（TDD：先写测试）
3. 并行标识 `∥` = 可与其他同阶段任务同时执行

---

## 阶段 1：基础设施（1 人，半天）

### 1.1 初始化 Quarkus 项目 ∥
- **需阅读**：`技术选型.md`、`构建与部署.md`
- **内容**：创建 Maven 项目，配置 pom.xml（Quarkus 3.x + ROME + JSoup + jieba + SQLite + Panache）
- **验收**：`./mvnw quarkus:dev` 启动成功

### 1.2 配置文件 ∥
- **需阅读**：`技术选型.md`、`构建与部署.md`
- **内容**：`application.properties` — SQLite WAL 模式、静态文件路径、日志配置
- **验收**：启动后 `data/rsscount.db` 自动创建

### 1.3 创建所有 Entity
- **需阅读**：`数据库设计.md`
- **内容**：12 个 Panache Entity（RssGroup, RssSource, Task, Report, News, Tag, Draft, DraftVersion, Settings 及中间表）
- **验收**：Quarkus 启动后自动建表，表结构与 `数据库设计.md` 一致
