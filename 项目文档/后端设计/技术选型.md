# 技术选型

## 概述

本项目是一个 RSS 新闻聚合 + AI 辅助内容生产工具，需要支持 RSS 拉取、HTML 正文提取、中文分词去重、AI 文本生成、SSE 实时推送等功能。部署目标为单 Docker 镜像。

## 技术栈

| 层面 | 选型 | 版本 | 说明 |
|---|---|---|---|
| 语言 | Java | 21+ | 利用 Virtual Threads 实现高并发 RSS 拉取 |
| 框架 | Quarkus | 3.x LTS | 支持 GraalVM Native Image，冷启动 <1s |
| 编译 | GraalVM Native Image | 21+ | 编译为单二进制，镜像 ~100MB |
| 数据库 | SQLite (WAL 模式) | 3.x | 单文件，零配置，WAL 避免读写锁冲突 |
| ORM | Hibernate + Panache | Quarkus 内置 | Active Record 模式，简化 CRUD |
| RSS 解析 | ROME | 1.x | 业界最成熟的 Java RSS/Atom 解析库 |
| HTML 解析 | JSoup | 1.x | Java 标准 HTML 解析器，用于正文提取和清洗 |
| 中文分词 | jieba-analysis | 1.x | 结巴分词 Java 版，用于 SimHash 前的分词 |
| SSE | Quarkus RESTEasy Reactive | 内置 | SseEventSink 原生支持 |
| HTTP 客户端 | Quarkus REST Client Reactive | 内置 | 调用 AI API (OpenAI-compatible) |
| 容器化 | Docker (multi-stage) | - | 构建阶段用 GraalVM，运行阶段用 distroless |

## 关键库依赖

### ROME — RSS/Atom 解析
```xml
<dependency>
    <groupId>com.rometools</groupId>
    <artifactId>rome</artifactId>
</dependency>
```
- 支持 RSS 1.0 / 2.0 / Atom / JSON Feed
- 自动处理编码、时间格式
- 能提取 title, link, description, author, publishedDate, categories

### JSoup — HTML 解析与正文提取
```xml
<dependency>
    <groupId>org.jsoup</groupId>
    <artifactId>jsoup</artifactId>
</dependency>
```
- HTML 清洗（去除脚本、样式、广告节点）
- 正文提取：参考 Mozilla Readability 算法自行实现
- 图片提取：`doc.select("img")` 取第一张合适尺寸的作为头图

### jieba-analysis — 中文分词
```xml
<dependency>
    <groupId>com.huaban</groupId>
    <artifactId>jieba-analysis</artifactId>
</dependency>
```
- 用于 SimHash 计算前对标题进行中文分词
- 加载默认词典，支持自定义词典扩展

### Panache + SQLite
```xml
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-hibernate-orm-panache</artifactId>
</dependency>
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-jdbc-sqlite</artifactId>
</dependency>
```
- Active Record 模式：`entity.persist()`, `Entity.find(...)`, `Entity.delete(...)`
- SQLite WAL 模式配置：`spring.datasource.jdbc-url=jdbc:sqlite:data/rsscount.db?journal_mode=WAL&busy_timeout=5000`

## 并发模型

### Virtual Threads（Java 21+）
- 每 RSS 源一个 Virtual Thread 并发拉取，无线程池管理负担
- 格式化线程池：固定 5 个 Platform Thread，批量并行处理

```java
// RSS 并发拉取
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    for (RssSource source : sources) {
        executor.submit(() -> fetchSource(source));
    }
}
```

### 生产者-消费者模式
- 拉取线程（生产者）→ BlockingQueue → 格式化线程池（消费者）
- 拉取一条 → 去重通过 → 立即入队 → 格式化线程消费

## AI 集成

### 接口抽象
```java
public interface AiProvider {
    String generateText(String systemPrompt, String userPrompt, 
                        String model, double temperature);
}
```
- 实现：OpenAiCompatibleProvider（调用 OpenAI-compatible API）
- 配置：apiUrl, apiKey, model 存储在 Settings 表中
- 超时：概览生成 30s，稿件生成 120s
- 失败降级：AI 不可用时概览留空，不阻塞任务完成

### Dockerfile 概要
```dockerfile
# 构建阶段
FROM ghcr.io/graalvm/native-image:21 AS build
COPY . /src
RUN mvn package -Pnative

# 运行阶段
FROM gcr.io/distroless/base
COPY --from=build /src/target/rss-count-runner /app/
ENTRYPOINT ["/app/rss-count-runner"]
```
