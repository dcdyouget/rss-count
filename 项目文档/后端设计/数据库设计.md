# 数据库设计

## 概述

数据库：SQLite，WAL 模式。所有时间均为 UTC+8 存储（TIMESTAMP 类型）。
Panache Active Record 模式，实体类直接继承 `PanacheEntity`。

## ER 关系

```
RssGroup ──(RssSourceGroup)── RssSource
                                  │
Task ──1:1── Report ──1:N── News ──(NewsTag)── Tag
                                  │
                                  ├── sourceRssId → RssSource (SET NULL on delete)
                                  │
Draft ──(DraftNews)── News         │
  │                                │
  └──1:N── DraftVersion            │
                                   │
Settings (单行，id=1)              │
```

## 表定义

### 1. rss_group（RSS 分组）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| name | VARCHAR(100) | NOT NULL, UNIQUE | 分组名称 |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

### 2. rss_source（RSS 源）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| url | VARCHAR(2048) | NOT NULL, UNIQUE | RSS 链接地址 |
| name | VARCHAR(200) | NOT NULL | RSS 源名称 |
| icon_path | VARCHAR(500) | | 本地存储的网站图标路径，如 `/static/icons/1.png` |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 添加时间 |
| last_fetch_at | TIMESTAMP | | 最近拉取时间 |
| total_fetched | INT | NOT NULL, DEFAULT 0 | 累计拉取新闻总数 |
| is_active | BOOLEAN | NOT NULL, DEFAULT TRUE | 软删除标记 |

### 3. rss_source_group（源-分组关联）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| rss_source_id | BIGINT | NOT NULL, FK → rss_source(id) ON DELETE CASCADE | |
| rss_group_id | BIGINT | NOT NULL, FK → rss_group(id) ON DELETE CASCADE | |

联合主键 (rss_source_id, rss_group_id)

### 4. task（任务）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| name | VARCHAR(200) | NOT NULL | 任务名称，前端传入 |
| time_range_start | TIMESTAMP | NOT NULL | 检索起始时间 |
| time_range_end | TIMESTAMP | NOT NULL | 检索结束时间 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'RUNNING' | RUNNING / COMPLETED / FAILED |
| source_type | VARCHAR(10) | NOT NULL | ALL / GROUP / SOURCE / MIXED |
| source_config | TEXT | | JSON：{"groupIds":[1,2],"sourceIds":[5]} |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |
| started_at | TIMESTAMP | | 开始执行时间 |
| ended_at | TIMESTAMP | | 结束时间 |
| error_message | VARCHAR(2000) | | 失败原因 |

索引：
- `idx_task_status` ON (status)
- `idx_task_created_at` ON (created_at DESC)

### 5. report（报告）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| task_id | BIGINT | NOT NULL, UNIQUE, FK → task(id) | 1:1 关联任务 |
| name | VARCHAR(200) | NOT NULL | 报告名称 |
| time_range_start | TIMESTAMP | NOT NULL | |
| time_range_end | TIMESTAMP | NOT NULL | |
| news_count | INT | NOT NULL, DEFAULT 0 | 包含新闻条数 |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

索引：
- `idx_report_created_at` ON (created_at DESC)

### 6. news（新闻）— 核心实体

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| report_id | BIGINT | NOT NULL, FK → report(id) | 所属报告 |
| title | VARCHAR(500) | NOT NULL | 清洗后的标题 |
| summary | TEXT | | 概览（AI 生成或原文提取） |
| author | VARCHAR(100) | NOT NULL, DEFAULT '未知' | 作者 |
| raw_content | TEXT | | 原始 HTML 正文 |
| structured_content | TEXT | | 结构化正文 JSON，格式见下文 |
| source_rss_id | BIGINT | FK → rss_source(id) ON DELETE SET NULL | 来源 RSS |
| source_rss_name | VARCHAR(200) | | 冗余字段：源名称（源被删后保留） |
| source_url | VARCHAR(2048) | | 原文链接 |
| header_image_url | VARCHAR(2048) | | 头图路径 |
| category | VARCHAR(50) | | 分类 |
| published_at | TIMESTAMP | | 发布时间（UTC+8） |
| sim_hash | BIGINT | | 64 位 SimHash 指纹 |
| content_length | INT | NOT NULL, DEFAULT 0 | 正文长度（去重时保留更长者） |
| is_read | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否已读 |
| in_material_pile | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否在素材堆 |
| material_pile_added_at | TIMESTAMP | | 加入素材堆时间 |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

索引：
- `idx_news_report_id` ON (report_id)
- `idx_news_title` ON (title)
- `idx_news_sim_hash` ON (sim_hash)
- `idx_news_material_pile` ON (in_material_pile, material_pile_added_at DESC) WHERE in_material_pile = TRUE
- `idx_news_created_at` ON (created_at DESC)

### 7. tag（标签库）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| name | VARCHAR(50) | NOT NULL, UNIQUE | 标签名 |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

### 8. news_tag（新闻-标签关联）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| news_id | BIGINT | NOT NULL, FK → news(id) ON DELETE CASCADE | |
| tag_id | BIGINT | NOT NULL, FK → tag(id) ON DELETE CASCADE | |

联合主键 (news_id, tag_id)

### 9. draft（稿件）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| name | VARCHAR(200) | NOT NULL | 稿件名称 |
| prompt | TEXT | | 用户自定义提示词 |
| temperature | DOUBLE | NOT NULL, DEFAULT 0.7 | LLM 温度 (0.0-2.0) |
| style | VARCHAR(50) | | 文稿风格（如"正式""轻松"） |
| target_platform | VARCHAR(50) | | 目标平台（知乎/头条/小红书...） |
| latest_version | INT | NOT NULL, DEFAULT 0 | 最新版本号 |
| latest_content | TEXT | | 最新版本内容（冗余，加速查询） |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |
| updated_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

### 10. draft_version（稿件版本历史）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTOINCREMENT | |
| draft_id | BIGINT | NOT NULL, FK → draft(id) ON DELETE CASCADE | |
| version | INT | NOT NULL | 版本号（1, 2, 3...） |
| content | TEXT | | AI 生成的内容（原始字符串） |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

唯一约束：(draft_id, version)

### 11. draft_news（稿件-新闻关联）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| draft_id | BIGINT | NOT NULL, FK → draft(id) ON DELETE CASCADE | |
| news_id | BIGINT | NOT NULL, FK → news(id) ON DELETE CASCADE | |
| sort_order | INT | NOT NULL, DEFAULT 0 | 排序 |

联合主键 (draft_id, news_id)

### 12. settings（系统设置，单行）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 恒为 1 |
| task_interval_hours | INT | NOT NULL, DEFAULT 6 | 定时任务间隔（小时） |
| ai_api_url | VARCHAR(500) | | AI 接口地址 |
| ai_api_key | VARCHAR(200) | | AI API Key |
| ai_model | VARCHAR(100) | | AI 模型名 |
| default_group_id | BIGINT | FK → rss_group(id) ON DELETE SET NULL | 默认 RSS 分组 |
| updated_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | |

## structured_content JSON 格式

```json
[
  {"type":"heading","level":2,"text":"章节标题"},
  {"type":"paragraph","text":"段落正文内容..."},
  {"type":"image","src":"/static/images/news123_img1.jpg","alt":"图片描述"},
  {"type":"blockquote","text":"引用内容"},
  {"type":"list","ordered":false,"items":["项目1","项目2"]},
  {"type":"code","language":"python","text":"print('hello')"}
]
```

类型枚举：`heading`, `paragraph`, `image`, `blockquote`, `list`, `code`

## 初始化 SQL

应用首次启动时自动执行（或通过 Flyway migration）：

```sql
PRAGMA journal_mode=WAL;
PRAGMA busy_timeout=5000;
PRAGMA foreign_keys=ON;

-- 插入默认设置
INSERT OR IGNORE INTO settings (id, task_interval_hours) VALUES (1, 6);
```
