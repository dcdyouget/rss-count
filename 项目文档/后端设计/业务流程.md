# 业务流程

## 任务状态机

```
                  POST /tasks
                      │
                      ▼
              ┌──────────────┐
              │   RUNNING     │◀── 重启恢复
              │              │
              │ 拉取+格式化   │
              │ 并行执行      │
              └──┬────────┬──┘
                 │        │
        全部完成 │        │ 不可恢复错误
                 ▼        ▼
         ┌──────────┐ ┌──────────┐
         │COMPLETED │ │  FAILED  │
         └──────────┘ └──────────┘
```

- **RUNNING**：任务执行中（拉取与格式化并行），SSE 持续推送进度
- **COMPLETED**：全部源拉取完毕 + 全部新闻格式化完成
- **FAILED**：全部源拉取失败或发生不可恢复错误，`errorMessage` 记录原因

## 并行流水线执行流程

```
POST /tasks 创建任务
  │
  ├─ 1. 事务：INSERT Task(RUNNING) + INSERT Report
  ├─ 2. 异步启动 TaskExecutor
  │
  └─ TaskExecutor.execute(task)
       │
       ├── 解析源列表 ──────────────────────────┐
       │   sourceType=ALL   → 全部 RssSource     │
       │   sourceType=GROUP → 展开分组 → 去重合并 │
       │   sourceType=SOURCE→ 直接使用 sourceIds  │
       │   sourceType=MIXED → GROUP + SOURCE 合并 │
       │                                         │
       ├── 拉取（Virtual Threads，每源一线程）    │
       │   ┌── Source A ─→ 拉取 → 清洗 → 去重 ─┐ │
       │   ├── Source B ─→ 拉取 → 清洗 → 去重 ─┤ │
       │   └── Source C ─→ 拉取 → 清洗 → 去重 ─┘ │
       │                    │                    │
       │                    ▼                    │
       │          ┌─────────────────┐            │
       │          │  BlockingQueue  │            │
       │          └────────┬────────┘            │
       │                    │                    │
       ├── 格式化（固定 5 线程池）                │
       │   ┌─ Thread 1 ─→ 格式化 News A1 ─┐      │
       │   ├─ Thread 2 ─→ 格式化 News A2 ─┤      │
       │   ├─ Thread 3 ─→ 格式化 News B1 ─┤      │
       │   ├─ Thread 4 ─→ 格式化 News B2 ─┤      │
       │   └─ Thread 5 ─→ 格式化 News C1 ─┘      │
       │                    │                    │
       │                    ▼                    │
       │              持久化 News                │
       │                                         │
       ├── SSE 推送（每次拉取/格式化完成即推送）   │
       │                                         │
       └── 全部完成 → task.status = COMPLETED    │
                      task.endedAt = now          │
                      report.newsCount = 总数     │
```

### 去重策略（拉取阶段即时执行）

每拉取到一条新闻，立即执行三级去重（仅与**当前任务**已拉取的新闻比对）：

1. **URL 精确匹配**：`SELECT id FROM news WHERE report_id = ? AND source_url = ?`
2. **标题精确匹配**（清洗后）：`SELECT id FROM news WHERE report_id = ? AND title = ?`
3. **SimHash 近似匹配**：`SELECT id, sim_hash FROM news WHERE report_id = ?` → 汉明距离 ≤ 3 判定重复

如果重复：
- 比较 `contentLength` → 保留正文更长者
- 更新旧记录（覆盖 title/summary/content/simHash 等）

### 新闻格式化（每条新闻执行）

```
格式化 News:
  ├─ ① 标题：已清洗
  ├─ ② 概览：
  │     原文有 description → 直接使用
  │     原文无 → 取正文前 1000 字 → AI 生成 200 字概览
  │     同时从标签库匹配/创建标签（AI 返回）
  ├─ ③ 作者：meta 提取 → 无则 "未知"
  ├─ ④ 记录 sourceRssId, sourceRssName, sourceUrl
  ├─ ⑤ 正文格式化：HTML → JSoup 清洗 → 提取段落/图片/标题 → 结构化 JSON
  ├─ ⑥ 头图：正文第一张图片 → 下载到 /static/images/ → headerImageUrl
  │          无图片 → 使用 RssSource.iconPath
  ├─ ⑦ 时间规范化：统一转为 UTC+8，存储 TIMESTAMP
  └─ ⑧ SimHash：jieba 分词 → TF-IDF 加权 → hash 合并降维 → 64位 Long
```

## SSE 进度推送

### 订阅端点

```
GET /api/v1/tasks/{id}/stream
Accept: text/event-stream
```

### 事件格式

**progress 事件**（拉取与格式化进度同时推送）：
```
event: progress
data: {"pulling":{"done":false,"currentSource":"36氪","sourceProgress":"3/15","totalFetched":42},"formatting":{"done":false,"formatted":8,"total":42,"currentAction":"正在生成概览"}}
```

**complete 事件**：
```
event: complete
data: {"reportId":15}
```

**error 事件**：
```
event: error
data: {"message":"全部RSS源拉取失败：连接超时"}
```

### 实现要点

- Quarkus `SseEventSink` + `@Produces(MediaType.SERVER_SENT_EVENTS)`
- TaskExecutor 持有 SseEventSink 引用，每次进度变化时 `sink.send(event)`
- 客户端断开连接 → `sink.close()` → TaskExecutor 移除该 sink
- 支持多客户端同时订阅同一个任务

## 定时任务（TaskScheduler）

```
@Scheduled (每隔 Settings.taskIntervalHours 小时触发)
  │
  ├─ 1. 检查是否有 RUNNING 状态的任务
  │     有 → 跳过本次（防重叠）
  │
  ├─ 2. 获取时间范围
  │     timeRangeStart = 上次 COMPLETED 任务的 endedAt
  │                      （无历史 → 24 小时前）
  │     timeRangeEnd   = 当前时间
  │
  ├─ 3. sourceType = ALL
  │    （如果 Settings.defaultGroupId 不为空 → sourceType=GROUP）
  │
  ├─ 4. 生成任务名称：日期 + "第N次自动任务"
  │
  └─ 5. 创建 Task + Report → TaskExecutor.execute()
```

- 设置变更后**下次触发时自动生效**，无需重启
- 可通过设置 `taskIntervalHours = 0` 禁用定时任务

## 服务重启恢复

应用启动时（`@ApplicationScoped` + `@Startup`）：

```
恢复流程:
  │
  ├─ SELECT task WHERE status = 'RUNNING'
  │
  ├─ 对每个 RUNNING 任务：
  │     ├─ 重新启动 TaskExecutor.execute(task)
  │     ├─ 已持久化的 News 不会丢失
  │     ├─ 拉取：跳过 lastFetchAt 在时间窗口内的源（避免重复拉取）
  │     └─ 格式化：SHOW News WHERE reportId = task.reportId
  │                 跳过已格式化的（structured_content IS NOT NULL）
  │
  └─ 日志：恢复 N 个未完成任务
```

## AI 调用流程

### 概览生成 + 标签匹配

```
AiService.generateSummary(news):
  │
  ├─ system: "你是一个专业的内容摘要生成助手。请根据以下文章内容，
  │           生成 200 字以内的中文摘要，并给出 2-5 个标签。"
  ├─ user: news.rawContent 前 1000 字
  │
  ├─ 调用 AI API（Settings 配置）
  │     timeout: 30s
  │     成功 → 解析返回的摘要 + 标签列表
  │     失败 → 返回 null（不阻塞任务）
  │
  └─ 标签处理：
       遍历 AI 返回的标签 → 查 tag 表 → 存在则关联，不存在则 INSERT 新标签
```

### 稿件生成

```
DraftService.generate(draft):
  │
  ├─ 加载 draft + 关联的 News
  │
  ├─ 构建 prompt：
  │     system: "你是一个{draft.style}风格的专业内容编辑。
  │              目标发布平台是{draft.targetPlatform}。"
  │     user:   "{draft.prompt}
  │
  │              参考素材：
  │              ---
  │              新闻1：{news[0].title}
  │              {news[0].structuredContent 提取纯文本}
  │              ---
  │              新闻2：..."
  │
  │     (素材总 token 超限时截断，优先保留标题 + 前 N 字)
  │
  ├─ 调用 AI API（Settings 配置）
  │     timeout: 120s
  │     成功 → 写入 DraftVersion(version = latestVersion + 1)
  │            更新 Draft.latestVersion + Draft.latestContent
  │     失败 → 返回 502 "AI 服务不可用: {原因}"
  │
  └─ 返回生成的 content
```

## 错误处理策略汇总

| 场景 | 处理 |
|---|---|
| 单个 RSS 源连接超时/不可达 | 跳过该源，记录日志，继续拉取其他源 |
| RSS 源返回格式异常 | 跳过该源，记录日志 |
| 单条新闻解析失败 | 跳过该条，继续 |
| HTML 正文提取失败 | structuredContent 置 null，保留 rawContent |
| AI API 调用失败（概览） | summary 留空，标签留空，不阻塞任务 |
| AI API 调用失败（稿件） | 返回 502，不持久化空内容 |
| **全部源拉取失败** | 任务 → FAILED，errorMessage 记录原因 |
| 进程崩溃（任务中断） | 重启后扫描 RUNNING 任务并恢复执行 |
| 定时任务触发时已有 RUNNING 任务 | 跳过本次，等下一轮 |
