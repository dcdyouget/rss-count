# 测试策略总览

## 测试金字塔

```
           ┌─────────┐
           │   E2E   │  3 条核心旅程，验证页面+接口+业务逻辑全链路
           │  3 条   │
           ├─────────┤
           │ 集成测试 │  前后端各自 25+ 条，验证 API 契约 + 组件交互
           │  50+ 条 │
           ├─────────┤
           │ 单元测试 │  前后端各自 20+ 条，验证纯逻辑/纯组件
           │  40+ 条 │
           └─────────┘
```

## 三个目标如何覆盖

| 目标 | 单元测试 | 集成测试 | E2E |
|---|---|---|---|
| **页面无问题** | 组件渲染、Props、事件回调 | 页面数据加载、交互流程、状态转换 | 真实浏览器操作全流程 |
| **接口无问题** | - | 请求校验、响应格式、错误码、边界值 | 真实 HTTP 请求 |
| **业务逻辑无问题** | SimHash/清洗/去重/正文提取 | 任务全生命周期、AI 降级、容错恢复 | 任务创建→完成→报告查看 |

## 测试运行顺序

```
开发阶段:
  1. 单元测试（秒级，每次保存运行）
  2. 集成测试（分钟级，提交前运行）
  3. E2E 测试（分钟级，合并前运行）

CI 流水线:
  Lint → 单元测试 (并行) → 集成测试 (并行) → E2E (触发条件: 合并到 main)
         └─ 前端 20 条       └─ 后端 25 条
         └─ 后端 20 条       └─ 前端 15 条
```

## 测试数据管理

### 夹具文件（`test-fixtures/`）

```
test-fixtures/
├── rss/
│   ├── valid-rss.xml          # 标准 RSS 2.0（3 条新闻）
│   ├── valid-atom.xml         # Atom 格式
│   ├── empty-feed.xml         # 空 feed
│   ├── malformed.xml          # XML 格式错误
│   └── chinese-encoding.xml   # GB2312 编码
├── html/
│   ├── article-with-images.html  # 含图片正文
│   ├── article-plain-text.html   # 纯文字正文
│   ├── article-no-content.html   # 只有导航无正文
│   └── article-nested.html       # 深层嵌套标签
├── opml/
│   ├── standard.opml          # 标准 OPML（2 分组 10 源）
│   ├── no-group.opml          # 无分组 OPML
│   └── empty.opml             # 空 OPML
└── ai/
    └── mock-responses.json    # Mock AI 响应（概览/标签/稿件）
```

### 后端测试

- 每个测试类独立临时 SQLite 文件
- `@BeforeEach` 插入夹具数据
- `@AfterEach` 删除临时文件
- WireMock 模拟 RSS 源 HTTP 响应和 AI API

### 前端测试

- MSW (Mock Service Worker) 模拟后端 API
- `handlers.ts` 统一管理 mock 响应
- 测试与真实后端 DTO 类型一致
