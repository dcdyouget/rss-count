# E2E 测试用例设计

## 工具

- **Playwright** — 启动真实浏览器，操作前端页面，验证后端数据
- 测试环境：前端 `localhost:5173` + 后端 `localhost:8080`（或 Docker Compose 一键启动）

## 测试数据准备

每个 E2E 测试前：
1. 启动后端（含测试 SQLite，预置 RSS 源和分组）
2. 启动前端开发服务器
3. Mock 外部依赖（RSS 源返回夹具 XML，AI API 返回夹具 JSON）

方式：Playwright `test.beforeEach` + 后端提供 `/api/test/reset` 重置数据库。

## E2E-1：完整任务流程（核心黄金路径）

**覆盖**：添加 RSS 源 → 创建任务 → SSE 进度 → 查看报告 → 查看新闻

| 步骤 | 操作 | 验证点 |
|---|---|---|
| 1 | 访问 `/rss-sources` | 页面正常加载，分组标签和源表格显示 |
| 2 | 点击"添加源" | Modal 弹出 |
| 3 | 输入 RSS 地址 → 选择分组 → 点"添加" | Modal 关闭，表格新增一行，图标已显示 |
| 4 | 访问 `/tasks` | 任务列表为空或显示历史任务 |
| 5 | 点击"创建任务" | 右侧 Drawer 滑出，名称预填 |
| 6 | 选择"1小时前"，源选"全部"，点"创建" | Drawer 关闭，列表新增一条 RUNNING 任务 |
| 7 | 点击该任务的"查看详情" | Drawer 滑出，显示三节点，SSE 日志滚动 |
| 8 | 等待 SSE complete 事件 | 三节点全绿，显示源列表 + 新闻列表 + "查看报告"按钮 |
| 9 | 点击"查看报告" | 跳转 `/reports/:id`，报告详情页加载 |
| 10 | 验证报告名称 + 新闻卡片 | 卡片网格显示，每张卡片有标题/概览/来源 |
| 11 | 点击第一张新闻卡片 | 切换到新闻内容视图，显示标题/正文/侧边栏 |
| 12 | 点击侧边栏"查看原文" | 新标签页打开原文链接 |
| 13 | 点击"标记已读" | 按钮变灰，状态更新 |
| 14 | 点击"← 返回报告" | 回到卡片网格视图 |
| 15 | 访问 `/dashboard` | 统计卡片更新，今日任务数+1 |

**预期耗时**：~30 秒（含 Mock RSS 返回）

## E2E-2：素材堆 + AI 稿件（内容生产流程）

**覆盖**：浏览新闻 → 加入素材堆 → 创建稿件 → AI 生成 → 编辑 → 复制

| 步骤 | 操作 | 验证点 |
|---|---|---|
| 1 | 先执行 E2E-1 或通过种子数据确保有新闻 | 新闻列表不为空 |
| 2 | 访问 `/news` | 新闻表格显示，有搜索栏 |
| 3 | 搜索关键词 → 筛选结果 | 表格仅显示匹配的新闻 |
| 4 | 勾选 3 条新闻 → 点"加入素材堆" | 提示"已加入 3 条"，按钮恢复 disabled |
| 5 | 访问 `/drafts` → 点"新建稿件" | 跳转 `/drafts/new` |
| 6 | 验证左侧素材堆 | 显示刚才加入的 3 条新闻 + 加入时间 |
| 7 | 输入提示词 → 调温度 → 选风格/平台 | 表单正常填写 |
| 8 | 点"AI 生成稿件" | 按钮 loading → 右侧编辑器填充内容 |
| 9 | 切换"纯文本"Tab | 显示纯文本内容 |
| 10 | 在编辑器中修改内容 | 自动保存提示"已保存"（2 秒后） |
| 11 | 点"复制内容" | 提示"已复制" |
| 12 | 粘贴到外部验证 | 剪贴板内容与编辑器内容一致 |
| 13 | 访问 `/drafts` | 列表显示新创建的稿件 |
| 14 | 再次编辑该稿件 → 点"AI 生成稿件" | 版本号 +1，新内容覆盖旧内容 |

**预期耗时**：~20 秒（含 Mock AI 返回）

## E2E-3：OPML 导入导出 + 源管理

**覆盖**：OPML 导入 → 验证源和分组 → 导出 → 验证导出文件

| 步骤 | 操作 | 验证点 |
|---|---|---|
| 1 | 访问 `/rss-sources` | 页面加载，当前源列表显示 |
| 2 | 记录当前源数量 | 用于后续对比 |
| 3 | 点击"导入 OPML" → 选择夹具文件 | 上传进度 → Modal 显示结果："创建 10 个，跳过 0 个" |
| 4 | 关闭结果 Modal | 表格刷新，源数量增加 10，分组标签增加对应分组 |
| 5 | 切换到某一分组 | 表格仅显示该分组下的源 |
| 6 | 右键分组名 → "重命名" → 输入新名称 | 分组名变更，标签更新 |
| 7 | 点击"导出 OPML" | 触发下载 |
| 8 | 验证下载文件 | 文件是有效 XML，包含所有源和分组 |
| 9 | 删除一个源（Popconfirm 确认） | 该源从表格消失 |
| 10 | 验证列表数 = 原数量 + 10 - 1 | 数据一致 |

**预期耗时**：~15 秒

## E2E-4：边界与异常场景

| 场景 | 操作 | 验证点 |
|---|---|---|
| **空状态** | 全新系统访问 Dashboard | 统计为 0，列表显示 Empty + 引导 |
| **表单校验** | 创建任务时不填名称 | "请输入任务名称" 错误提示 |
| **AI 不可用** | Mock AI 返回 500 → 生成稿件 | 错误提示"AI 服务不可用"，旧内容保留 |
| **RSS 不可达** | 添加源时输入不可达 URL | 错误提示"无法访问该 RSS 地址" |
| **删除确认** | 删除稿件 → 取消 | 稿件未被删除 |
| **SSE 断开** | 任务执行中关闭浏览器标签 → 重开 | 任务详情可重新打开，日志从上次断开处继续 |
| **设置生效** | 修改定时任务间隔 → 保存 | 设置页显示新值，刷新后仍为新值 |
